Privacy Policy

YouTube Mix Playlist Generator is designed to work locally inside your browser. It does not collect personal data or send usage data to a developer-controlled server.

Back to Home View on GitHub

Overview

The extension does not collect, store, transmit, or sell any personal information. All processing happens locally inside your browser.

Information We Collect

We do not collect personal information such as:

  • Name
  • Email address
  • Password
  • Payment information
  • Browsing or search history
  • Location data

Local Storage

The extension stores a small amount of data locally using Chrome Storage:

  • Theme preference
  • Language preference
  • Auto Copy preference
  • Show Button preference
  • Recently generated playlist history

This information never leaves your browser.

Network Requests

The extension communicates only with YouTube to generate playlist URLs. No user information is sent to external servers owned by the developer.

Permissions

  • tabs - Detects the active YouTube Mix page.
  • storage - Saves preferences and recent history locally.
  • https://www.youtube.com/* - Accesses YouTube Mix pages to generate playlists.

Third-Party Services

This extension does not use:

  • Advertising services
  • Analytics platforms
  • Tracking scripts
  • Remote databases
  • User profiling services

Changes

This policy may be updated in future versions of the extension to reflect new features or improvements.
