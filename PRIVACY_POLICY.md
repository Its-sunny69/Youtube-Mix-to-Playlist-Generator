# Privacy Policy

_Last updated: August 2026_

## Overview

YouTube Mix Playlist Generator is designed with privacy in mind.

The extension does **not** collect, store, transmit, or sell any personal information.

## Data Collection

This extension does **not** collect:

- Personal information
- Email addresses
- Passwords
- Browsing history
- Search history
- Financial information
- Health information
- Location data

## Local Storage

The extension stores the following data **locally** using Chrome Storage:

- Theme preference
- Language preference
- Auto Copy preference
- Show Button preference
- Recently generated playlist history

This data never leaves your browser.

## Network Requests

The extension communicates only with:

- YouTube

These requests are required to generate playlist URLs.

No user information is transmitted to any third-party server.

## Third Parties

The extension does not use:

- Analytics
- Advertising
- Tracking
- Remote databases
- External APIs for user data

## Changes

This Privacy Policy may be updated in future versions of the extension.

For questions or suggestions, please open an issue on the GitHub repository.
